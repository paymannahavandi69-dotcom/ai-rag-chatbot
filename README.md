An intelligent conversational chatbot built with Python and Streamlit. It uses Retrieval-Augmented Generation (RAG) to answer questions accurately based on custom documents.

## 🛠️ Tech Stack
- **Python** (Core logic)
- **Streamlit** (User Interface)
- **LangChain** (RAG Pipeline)
- **ChromaDB** (Vector Database for document retrieval)
- **Groq API** (LLM for generating answers)

## ⚙️ How to run
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`
3. Create a `.env` file and add your `GROQ_API_KEY`.
4. Run the app: `streamlit run rag_app.py`
